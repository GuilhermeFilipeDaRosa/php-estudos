# Estudos de PHP

Repositório criado para registrar meus estudos e práticas com a linguagem PHP.

Aqui estão exercícios e exemplos desenvolvidos durante meu aprendizado, abordando conceitos como:

* Variáveis e tipos de dados
* Operadores
* Estruturas condicionais
* Laços de repetição
* Arrays
* Funções
* Manipulação de arquivos
* Programação Orientada a Objetos
* Tratamento e manipulação de dados

O objetivo deste repositório é acompanhar minha evolução na linguagem e servir como referência para os conceitos estudados.

## Tecnologias

* PHP 8
* Git
* GitHub
